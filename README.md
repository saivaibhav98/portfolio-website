## 🛠️ Local Development

```bash
# Clone the repository
git clone https://github.com/saivaibhav98/portfolio.git
cd portfolio

# Install dependencies
npm install

# Start local development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```
